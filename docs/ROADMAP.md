# Roadmap

## v0.1 — Foundation (implemented in source)
- Deterministic JavaScript analytics pipeline
- Per-user memory storage abstraction
- Study summaries and subject aggregates
- Pattern detection and trend estimates
- Exam / subject priority ranking
- Adaptive plan proposals
- Explainable recommendations
- Node test suite

## v0.2 — Owj integration
- Map the real Owj session, plan, profile and exam schema
- Add Capacitor Preferences / secure storage adapter
- Add event queue, deduplication and analysis throttling
- Add Persian UI copy and evidence display
- Run tests against anonymized realistic scenarios

## v0.3 — Quality
- Backtest and calibrate confidence
- Better baselines and seasonality
- User feedback on recommendation usefulness
- Transparent memory review/reset screen
- Better overload and repeated-plan-failure detection

## Later
- Optional consent-based cross-device memory sync
- Optional on-device ML only after measurable evaluation
- Additional capabilities only when supported by data and tests
